# angelamihomo-icons

AngelaMihomo 的自有图标分发仓：内置图标集（Qure 风格 SVG）的完整镜像，由项目自有仓库分发，不再依赖上游仓库。

## 内容

- `icon/svg/common/`：通用图标 1790 个
- `icon/svg/flag/`：地区与组织旗帜图标 270 个
- `licenses/`：各来源素材的原始许可文本
- `THIRD_PARTY_NOTICES.md`：第三方素材与许可说明（随镜像原样保留）

## 来源与致谢

本仓图标镜像自 Qure-Style-SVG 图标集，来源链如下：

- 原始图标集：[aaANDkk/Qure_Style_SVG](https://github.com/aaANDkk/Qure_Style_SVG)，作者 aaANDkk，Qure 风格 SVG 图标集（视觉风格源自 Koolson/Qure，详见 `THIRD_PARTY_NOTICES.md`）。
- 镜像快照取自 appshubcc/Qure_Style_SVG（2026-11-17），该分叉由 Bettbox 项目维护。
- 本仓由 AngelaMihomo 项目（dukangalex）建立与维护，仅作分发镜像；图标的著作权与许可归各自权利人所有，各项素材继续适用其原有许可，不以单一许可覆盖整个图标集。

感谢 aaANDkk 与所有上游贡献者。

## 维护

随 AngelaMihomo 项目维护节奏同步更新：上游图标集有实质更新时重新镜像，并在此记录快照日期。

# angelamihomo-icons (English)

The AngelaMihomo project's own icon distribution repository: a complete mirror of its built-in icon set (Qure-style SVGs), served from a project-owned repository instead of the upstream one.

## Contents

- `icon/svg/common/`: 1790 general icons
- `icon/svg/flag/`: 270 region and organization flag icons
- `licenses/`: original license texts for all source materials
- `THIRD_PARTY_NOTICES.md`: third-party materials and license notes (preserved as-is from the source)

## Source and credits

The icons in this repository are mirrored from the Qure-Style-SVG icon set. Provenance chain:

- Original icon set: [aaANDkk/Qure_Style_SVG](https://github.com/aaANDkk/Qure_Style_SVG) by aaANDkk (visual style originating from Koolson/Qure; see `THIRD_PARTY_NOTICES.md`).
- Mirror snapshot taken from appshubcc/Qure_Style_SVG on 2026-11-17, a fork maintained by the Bettbox project.
- This repository is created and maintained by the AngelaMihomo project (dukangalex) purely as a distribution mirror. Copyright and licenses remain with their respective holders; each asset stays under its original license rather than a single blanket license.

Thanks to aaANDkk and all upstream contributors.

## Maintenance

Updated in step with AngelaMihomo's maintenance cadence: when the upstream icon set changes materially, the mirror is refreshed and the snapshot date is recorded here.
